# ADR-0002：会话策略与防泄漏边界

| 字段 | 值 |
|---|---|
| 状态 | Accepted |
| 实现 | Planned（M11–M12） |
| 日期 | 2026-09-02 |

## 决定

剪贴板、水印、桌面背景和设备重定向属于同一份版本化 `desktop_policy`，不实现为分散在客户端、镜像和桌面记录上的独立开关。策略可分配到全局、镜像、桌面池、桌面、用户或组；连接时由控制面解析出不可变快照并绑定会话 ID、用户、设备和过期时间。

安全能力采用“最严格者优先”，近层级不能放宽上层明确禁止的能力；品牌资源采用“最近作用域优先”。每次建联都记录策略版本、快照哈希和各执行端的应用结果。

首批字段：

- `clipboard_mode`: `disabled`、`text_only`、`bidirectional`。
- `file_transfer`、`drive_redirection`、`printer_redirection`、`usb_redirection`。
- `audio_input`、`audio_output`。
- `watermark`: 开关、模板、透明度、密度；模板变量只允许用户、设备、会话 ID 和时间。
- `desktop_background`: 受管资源 ID、SHA-256、显示方式和是否锁定。

## 强制执行

控制面在 RDP 描述符中返回签名策略快照。客户端必须根据快照关闭 FreeRDP 的剪贴板、磁盘、打印机和设备通道，但客户端不是唯一安全边界：

- Windows Guest Agent 同时应用 Remote Desktop Services 的设备/资源重定向策略，并管理桌面和锁屏背景。
- Debian Guest Agent 同时管理 xrdp 通道和 XFCE 背景。
- Guest Agent 回报已应用的策略哈希；强制策略未应用或哈希不一致时，Broker 拒绝签发新的连接描述符。
- 水印优先由 Guest Agent 的会话内顶层覆盖层渲染，客户端再叠加一层作为纵深防御。外部相机和操作系统之外的采集无法被软件绝对阻止，产品文案不得声称“不可截图”。

背景图片进入受控资源库，上传时校验类型、尺寸和哈希；会话只引用不可变资源版本，不直接接受任意 URL。

## 排期

| 阶段 | 优先级 | 交付 |
|---|---|---|
| M11.1 | P0 | 数据表、作用域/解析器、管理 API、策略快照签名、审计与能力协商 |
| M11.2 | P0 | macOS + Debian 13 + Windows 的剪贴板禁用、磁盘/文件重定向禁用，受管桌面背景；未应用则拒绝建联 |
| M12.1 | P1 | 会话水印，包含用户/设备/会话/时间，补齐注销、重连、多显示器和 DPI 验收 |
| M12.2 | P1 | 打印、USB、音频、拖放控制，策略漂移告警和合规状态页；同步 Windows/Linux 客户端 |

## 验收边界

“禁止 copy”不是一个布尔值。验收必须分别证明系统剪贴板、文件拖放、RDP 磁盘映射、打印到文件和客户端截图策略；关闭剪贴板不能被当作完整的数据防泄漏能力。水印需覆盖重连、多显示器、全屏和缩放，但只作为追责与威慑，不作为单独的数据保护边界。

## Alternatives

- 只在客户端隐藏剪贴板：实现快，但篡改客户端即可绕过，拒绝。
- 为每种能力各建一套配置：短期简单，解析顺序和审计会漂移，拒绝。
- 先做水印再做策略协议：可见度高但没有可信执行基础，延后到 M11 闭环之后。
