# UI 设计语言

## 定位

管理控制台是管理员和专业用户长时间操作的工具，不是营销页面。信息要能快速扫描，但只显示当前任务所需的信息；状态、错误和下一步必须直接可操作。

视觉语言由本仓库拥有。首批语言为简体中文和英文，导航与按钮按更长的英文标签预留空间。浅色与深色从第一版同时支持，并跟随或覆盖系统外观。管理员、桌面用户和 AI 监督者共用组件，但界面密度按角色区分。

产品名和所有新技术标识统一为 `VC Workspace` / `vc-workspace`：Web 标题、登录品牌、macOS 应用名、远程桌面窗口标题、包名、环境变量、PVE 标签、Guest Agent、来宾状态目录和用户文档均不得继续产生旧名称。已有部署的旧环境变量、PVE 标签、App Link、钥匙串项和来宾 Agent 路径只在兼容层读取，不再写入新资源。

官方标志为 `Agent Fabric`：中心工作空间连接三个不对称节点，分别承载集群资源、用户终端与 AI Agent 的关系。主标志与应用图标的唯一源文件位于 `assets/brand/`；Web Landing、登录页、控制台、favicon 与 macOS Bundle 必须从这些资产派生，不在各端重画近似版本。应用图标固定使用暖黑底与米白标志，在浅色和深色主题中均不着色、渐变或添加状态装饰。官方品牌标志只承担身份识别，不复用为功能按钮图标。

## 公共 Landing Page

根路径是给首次接触项目的自托管用户、基础设施团队和开源贡献者阅读的项目入口，属于一页读完并完成一次选择的 pitch surface；`/console` 才是操作应用。视觉语言仍由本仓库拥有，不另起一套营销主题。简体中文和英文同时交付，短导航与按钮按更长文案预留两倍伸缩空间；浅色和深色均为首发状态。

- 首屏只承载产品名、一句明确定位、一个主操作和一份能证明闭环的产品结构图。主操作进入 `/console`；GitHub 是同尺寸、弱填充的次操作。
- 定位必须点明 PVE、自托管工作空间、原生客户端和 MCP，不使用“下一代”“企业级”“无缝”等无法验证的形容词。
- 首屏之后只解释仓库中已经存在的四条能力边界：控制平面、原生客户端、镜像与 GPU、Agent 与 MCP；不为尚未形成闭环的功能创建占位页面。
- 公开仓库地址固定为 `https://github.com/Veritas-Calculus/vc-workspace`。仓库第一次 push 前不展示 Star、Release、版本号、许可证类型或可复制安装命令；这些信息只能由真实仓库状态生成。
- Landing 与控制台共享品牌、主题和语言控制。公开页语言当前保存在本地偏好中；在正式公开部署前再决定并实现可索引的语言路径与 `hreflang`，不能把当前客户端切换误报为 SEO 完成。
- 首屏只允许一个填充按钮；不使用持续动画、入场隐藏、背景光效或滚动劫持。交互只保留现有短时 hover/focus 反馈，并尊重 `prefers-reduced-motion`。
- 文本均来自统一消息目录。标题允许自然换行，不截断；导航允许换行或收起；架构标签与代码标识保持 LTR；根节点在 320–1280px 不得产生横向滚动。

## 视觉规则

- 基础色使用无彩中性色，主操作使用墨色反转，不引入无来源品牌色。
- 成功、警告、信息和错误只用于真实语义状态；同一状态在全产品使用同一 Token。
- 界面依靠层级、留白和 1px 分隔线组织，不使用投影。
- 圆角只有 `control`、`panel`、`pill` 三个命名用途；普通工作区面板保持克制。
- 标题使用短字号阶梯；表格、表单和导航优先保证扫描节奏。
- 动效只用于即时状态变化，并尊重 `prefers-reduced-motion`。

## 信息规则

- 不显示“OIDC 可用”“企业级”“已就绪”等无法触发动作、不能帮助判断的标签。
- 品牌、页面标题、说明句和主按钮不重复表达同一件事；登录页只保留品牌、凭证字段和登录动作。
- 登录页的品牌与表单属于同一个居中内容组，间距保持一个普通章节级空隙；语言和主题工具悬置在视口角落，不再用独立顶栏把品牌与登录动作拆到视口两端。
- macOS 主窗口使用无标题栏样式，普通窗口保留系统红黄绿控制；全屏时显式隐藏系统窗口工具栏及重复控件，不能在重连重建内容后覆盖 Guest 顶部面板。退出全屏显式恢复工具栏可见性与系统控件；仅透明标题栏或恢复为自动模式不足以保证这一点。不在窗口顶部重复显示产品名或分隔条；产品名只在登录内容区出现一次。
- macOS 普通用户登录后进入“桌面库”：顶部只保留页面名、搜索、刷新和退出，不向用户暴露“弱网”或协议调参。数据面请求自动网络策略，服务器不支持时不能宣称动态适配已生效；特定带宽策略只能由管理策略或诊断工具注入。
- Guest 显示适配不增加普通用户开关或状态标签。Retina 字体、面板、光标与默认窗口边框按同一比例配合；仅在单屏桌面缩小时恢复越界的普通窗口，并计入窗口装饰尺寸，不重置自定义主题、布局组成或抢走焦点。GPU 是否生效以实际会话渲染器验收，不能用“已挂设备”的 UI 状态替代。
- Web 控制台侧栏底部的账号名称是账号入口，不新增只有一个功能的“设置”一级导航。本地账号在紧凑对话框中修改自己的平台密码；OIDC 账号不显示不可执行的密码表单，只说明密码由身份提供方管理。密码变更成功后保留当前 Web 会话，撤销其他 Web/Native 会话和活动桌面连接，并明确提示用户需要在其他设备重新登录。
- 桌面权限继续使用桌面行上的单一编辑入口，不增加“安全能力”统计卡或新的一级页面。对话框按“本地权限 / 数据传输 / 桌面外观”三个短分组排列；每项只显示名称和一条会影响用户体验的说明，启用状态由原生复选框表达，不使用状态徽章。保存是一次原子策略变更，运行中的桌面应立即收敛；策略没有在 Guest 与官方客户端两端形成可验证快照时拒绝签发新连接。
- “允许剪贴板”只指文本剪贴板；文件复制属于驱动器重定向，使用独立开关且默认关闭。官方 macOS 客户端不显示这些协议开关，只执行连接描述符中的策略。受管背景开启时使用仓库唯一品牌背景并在每次登录重新应用；关闭表示停止强制，不承诺恢复用户先前选择。策略版本、摘要和执行状态用于诊断与审计，不在普通用户连接界面展示。
- 控制台折叠为窄屏顶栏后保留账号、语言、主题和退出四个图标动作；在 480px 以下品牌区只显示官方标志，隐藏重复的产品文字，为这些操作保留 44px 触控目标且不产生页面横向滚动。
- macOS 冷启动、恢复登录、登录提交和桌面加载共享居中品牌图、28 pt 阶段标题和非百分比活动条；连接、取消、断开和失败共用桌面状态图。加载状态必须在默认窗口中一眼可辨，活动条、SF Symbol 替换和状态切换均遵守“减少动态效果”，不能退化为按钮角落的小型 `ProgressView`。
- macOS 桌面库使用响应式卡片网格，卡片不随宽窗口无限拉伸。卡片只展示桌面名、运行状态、VMID、节点、CPU/内存和当前操作；名称与节点单行截断，通过系统帮助文本暴露完整值。搜索同时匹配名称、VMID、节点和状态，无桌面、搜索无结果、首次加载和加载失败必须是四个不同状态。
- 单页面产品不显示只有一个入口的导航；概览数字若已能从紧邻表格直接读出，则不重复展示。
- 不制造装饰性统计卡；概览只保留会影响调度或需要处理的资源信息。
- 空状态说明原因并提供唯一下一步；错误状态保留在页面中并允许重试。
- 受保护 API 返回 401 时，整页跳回固定的 `/console?session=expired`，清除当前私有数据、弹窗和未提交的秘密，不在浏览器持久化密码草稿；只在登录表单中解释过期与未保存修改。匿名启动和登录密码错误不触发跳转，403 保留权限错误，不制造重新登录循环。
- 任务轮询只有一个在途请求，15 秒超时，临时错误按 2.4–30 秒退避；成功恢复继续读取同一 Job，不能重发创建/启停请求。状态不可读取时用一个原位错误和重试动作替代旧的“进行中”提示，不能同时暗示任务正在正常更新。权限拒绝或任务消失停止自动重试。
- 克隆恢复沿用“近期任务”的行操作，在列表下展开原位表单，不新增导航或模态层。管理员必须明确选择通过核对的任务并填写原因；响应不确定时收起提交表单，只允许查询原任务。关闭仅隐藏表单，不暗示服务器取消。任务登记与克隆完成分开表达。
- 列表默认截断长标识，完整值通过详情或复制动作获取。
- 管理端按真实工作流固定为“桌面 / 近期任务 / 基础设施 / 桌面镜像 / GPU 加速 / 访问控制 / 审计”七个一级工作区。普通用户只显示自己的“桌面”；其余工作区只对平台管理员显示。“访问控制”内部只用一组紧凑页签区分账号、组、桌面授权和 Guest 身份配置，直接维护本地/OIDC 用户、组成员关系、AI Agent、Personal/Shared 授权及 Linux/Windows 身份 Profile；桌面编辑只显示与其已识别 OS 平台兼容的 Profile。宽屏使用单一左侧导航，窄屏折叠为可横向滚动的顶部导航；不增加统计卡、装饰性概览或第三层导航。
- “桌面”只展示控制面明确标记为受管的实例，名称只用于展示和搜索，不能成为权限或能力判断依据。创建、启动和停止在当前工作区完成；异步结果统一进入“近期任务”。
- Web 桌面列表为每台受管桌面提供“在 VC Workspace 中打开”动作，使用 `vc-workspace://connect?vmid=<正整数>` 唤起 macOS 客户端；Landing Page 不展示没有目标桌面的空泛“打开 App”。链接只携带 VMID，不携带控制面 Token、密码、Guest 地址或 RDP 描述符。客户端必须先从当前绑定的控制面重新读取登录用户可见桌面，匹配后才可启动或连接；未登录时保留一次待处理目标并在登录成功后继续，非法或不可见目标只显示错误，不产生桌面副作用。
- 原生打开动作不能伪造浏览器内的“已打开”成功状态，也不使用计时器猜测客户端是否安装。Web 提供明确的链接名称与系统原生行为；发布安装包和稳定下载地址形成闭环后再增加安装兜底。
- macOS 远程桌面画面必须处于 VC Workspace 自己的视图树和应用生命周期内，不得要求用户安装、启动或切换到另一个 RDP 应用。会话页使用整块黑色画布承载原生 `NSView`，固定工具栏只保留断开、桌面名和全屏；“已连接”不再用文字重复画面已经表达的事实。
- macOS 建联采用单任务状态页，参考 AWS WorkSpaces 的 Pre-session / Transition / Reconnect 分层，但使用本项目的系统字体、SF Symbols 和克制中性色。点击卡片后立即离开桌面库，并在同一位置依次显示“正在启动桌面 / 正在准备桌面 / 正在连接”；不显示轮询秒数、弱网标签、Guest Agent、xrdp、端口或其他实现细节。三个阶段均可取消，取消后返回桌面库。会话必须等到原生 RDP 首个绘制帧到达并完成短暂稳定期后才替换状态页，不得把协议握手成功误当成用户已经看到桌面。
- 主动断开时先显示“正在断开连接”，完成后停留在“连接已断开”恢复页，不把连接关闭说成 Guest 已注销，也不保证异常断线后应用一定保留。明确的网络错误进入可取消的“正在恢复连接”，有限重试且每次重新校验授权；超限或不可自动重试的传输结束后，只读复核当前可见桌面，不为诊断签发新凭据。权限拒绝/桌面不可见进入“桌面不可用”，只提供返回并刷新桌面库；401 返回登录，复核失败保留中性错误及可执行动作，不猜测网络原因。迟到复核不得覆盖新连接、返回、注销或关窗。原始协议诊断留在日志中，各阶段互斥，不以桌面库顶部横幅代替。
- 全屏使用 macOS 原生窗口全屏，不另造沉浸模式。最大化、拖动和全屏共用“正在调整画面”，只覆盖远程画布，不遮挡顶部操作；完成依据是最新目标宽高的实际绘制帧，不是 resize 确认或固定延时。8 秒未到帧时回退可用缩放画面，并仅在此时提供“重新调整画面”，不得无限遮挡会话；冷登录被服务端丢弃的请求仍在 30 秒有界预算内退避重试，迟到的新帧自动结束回退。断开与窗口关闭都必须回收本地传输并退役连接凭据，不等同于注销 Guest 桌面；任务和会话分别绑定唯一标识，旧回调不能清除新连接，取消覆盖首帧稳定期及传输收尾瞬间。关闭主窗口不等同于退出应用：应用保留在 Dock，用户再次激活 Dock 图标时必须恢复同一个主窗口，并自动取消最小化或隐藏；只有显式退出才终止进程。鼠标、键盘和剪贴板由同一个 AppKit responder chain 处理。
- macOS 客户端固定为单窗口，不暴露“新建窗口”、窗口标签页或不可执行的 Help Book。应用菜单保留关于、设置、隐藏和退出；设置负责控制面连接检查；连接菜单按当前状态提供刷新、取消连接、断开、重新连接或返回桌面库；显示菜单只保留系统全屏；编辑与窗口菜单继续使用系统 responder chain。帮助菜单只链接项目主页和 Issue 页面。
- 窗口调整、系统缩放和全屏往返必须通过 RDP Display Control 改变 Guest 的真实桌面分辨率，不能只在客户端拉伸固定帧。远端像素尺寸使用 AppKit 内容区逻辑点乘当前 backing scale，最高 2×；同时提交匹配的 100%/200% Desktop Scale。连续拖动防抖，拖动结束、跨屏、缩放和全屏立即提交。Linux xrdp 未应用协议 DPI 时，由控制面在建联阶段把受限比例同步为 XFCE 96/192 Xft DPI；已经建立的 Linux 会话跨越 1×/2× 屏幕时，当前版本需要重新连接才能同步 DPI。旧帧可在协商期间临时缩放，服务端不支持动态分辨率时允许回退 Smart Sizing，但不得造成黑屏、模糊或输入坐标漂移。
- 全屏按钮必须跟随窗口的真实全屏状态切换图标和可访问名称，无论通过按钮或 macOS 系统窗口控制进入全屏都一致。发布验收至少覆盖最小窗口、默认窗口、宽窗口、系统缩放和一次全屏往返；每次都从 Guest 内读取实际分辨率，并在缩放后复测画面填充、鼠标命中和键盘焦点。
- “基础设施”集中展示 PVE 节点和存储；原始模板与普通 PVE VM 不混入最终用户的桌面列表。
- 受管桌面背景使用 `assets/brand/vc-workspace-desktop-background.svg` 作为唯一设计源：暖黑纯色底、低对比 Agent Fabric 标志和产品名，不使用渐变、宣传语、状态、用户信息或持续动画。主要图形必须落在 5:4 至 21:9 填充裁剪都可见的中央安全区；Debian 13 与 Windows 模板都内置同一派生 PNG，并以填充/裁剪方式适应分辨率。用户、设备、会话和时间只属于后续动态水印层，不能烘焙进静态背景。
- IaC 不增加独立的装饰性 Dashboard。资源 ID 在现有访问控制、镜像、GPU 与桌面工作流中保持稳定并可复制；Terraform/OpenTofu Provider 通过同一公开 API、权限判定、幂等语义和审计链路执行，计划阶段必须能够读取漂移，敏感值只能来自环境变量或外部 Secret Store。
- 用户、OIDC、会话策略和 AI 管理只有在对应 API 与可执行操作形成闭环后才加入导航，不使用空白页面预告路线图。
- 镜像列表只显示 OS、状态、模板 VMID、Agent 和编辑动作；ISO、软件源、CPU/内存/磁盘、固件/TPM 和 GPU 默认值放入编辑对话框，避免把低频配置铺满首屏。
- 镜像编辑对话框同时承担 Bootstrap：按“构建来源 / 硬件 / 可用性 / 构建模板”分组，Debian 展示软件与安全更新镜像源，Windows 展示驱动 ISO 和镜像名称；镜像源没有预置默认值，必须由管理员按所在环境填写。
- “构建模板”是明确的提交动作，一次性密码和产品密钥必须和持久配置分区，并说明不会保存。构建开始后关闭编辑入口，在镜像页原位显示进度和最新脱敏日志；成功状态为“验证中”，不能直接变成“可用”。
- 构建任务被服务端受理后，列表与进度区必须同时反映其状态，不能仍显示草稿和可编辑。镜像构建候选不属于用户桌面；当前模板以及未完成/失败构建目标必须由服务端统一排除，Web、原生客户端和 MCP 不各自猜测 PVE 标签。
- GPU 页面只显示档位、PVE 映射、可用性、状态与编辑动作，再单列 PVE 实际硬件。完整直通显示可分配设备数；mdev 显示指定类型的实时剩余实例数，不把两种口径混在一起。
- GPU 编辑对话框中的“创建 PVE 映射”默认收起；完整直通要求映射 ID 和一台当前可直通设备，mdev 只要求映射 ID 并自动收集支持该类型的节点。没有兼容设备时明确显示空状态且不能提交，不把宿主机准备步骤塞进对话框。
- 创建桌面只列出管理端已启用且构建状态为可用的镜像；选择 GPU 档位后，目标节点列表立即缩小到映射中实际可分配的节点。
- 审计工作区只显示时间、操作者、事件、目标和成功/失败结果；来源地址、客户端、原始事件类型及结构化详情按行展开。搜索和结果筛选由服务端执行，更早记录用游标加载；不复制任务统计，也不展示无操作价值的汇总卡。
- 溢出策略必须按内容类型声明：工作区导航窄屏横向滚动；数据表放在独立横向滚动容器；名称和任务详情在固定列中截断并用 `title` 暴露完整值；表单标签允许换行；页面根节点不得横向滚动。

## 刻意不做

- 不做渐变、玻璃、光晕和大面积阴影，它们会与高密度运维信息争夺注意力。
- 不使用大圆角卡片网格承载每个数字，它会把相关数据拆散成装饰模块。
- 不用徽章重复普通文案；徽章只表达状态或范围。
- 功能图标不用 Emoji 或临时手绘 SVG，统一使用 Lucide；官方品牌标志是身份资产，不受此规则约束。
- 不在页面上预告尚未实现或无法操作的功能。
- Landing 不做假指标、Star 计数、证言、Logo 墙、价格、FAQ、视频首屏、渐变光效或多段重复 CTA；它们都不能帮助首次访问者验证当前开源实现。
- MVP 不把 Universal Links 作为任意自托管部署的默认入口。它要求发布签名中的 Associated Domains 与站点上的双向关联文件，无法动态覆盖未知部署域名；项目拥有稳定 HTTPS 域名和签名发布链后，可把 Universal Link 作为 `vc-workspace://` 之上的可选可信跳转层。

## macOS 原生外观与动效

Mac 客户端服务于进入桌面和恢复连接，不复刻管理后台。沿用官方图标、SF 系统字体和中性色，功能图标使用系统 SF Symbols（Web 的 Lucide 规则不套用到原生端）；浅色/深色跟随系统，原生文案当前仅简体中文，不能用 Web 的双语验收代替。布局采用 macOS 逻辑点，最小窗口为 680×460，另验收 1000×700 和长桌面名称。

- `WorkspaceStyle` 统一表面、间距、圆角和字体；`WorkspaceActionStyle` 只定义 primary / secondary 两种命令，保持原生 Button 的键盘语义。登录、卡片连接、重连使用同一个主按钮；取消使用次按钮。系统菜单和设置继续使用原生控件，不额外造一套弹窗。
- 登录页保留一次品牌展示、可见字段标签和一个主操作，不重复占位文案，不在背景铺大 Logo；服务器配置继续按需展开。桌面卡片保留名称、状态和必要规格，卡片本身不是隐形按钮，连接操作具有明确边界。
- 登录服务器配置与系统设置共用连接检查结果：用户主动检查后原位显示成功或失败，可重试；自动启动探测不增加常驻成功标签。修改地址立即清除旧结果、取消旧请求，迟到回调不能写回系统能力或保存新地址；只读检查失败不得退出已有登录或桌面会话。
- 按下即时反馈，回弹采用无明显过冲的短弹簧；悬停只改变表面，不让卡片上下跳。焦点、按下与禁用分别可见。搜索即时本地过滤，不增加人为等待。
- 状态过渡使用共享图形、短距离位移和淡入淡出；不在整个窗口或远程 NSView 上套缩放动画，不通过动画计时器决定连接是否成功。连接阶段只由真实会话状态驱动；取消和重试无需等待动画结束。
- 动态效果减少时取消位移、旋转和脉冲，保留静态阶段图与轻量颜色反馈；后台窗口不持续刷新装饰动画。减少透明度时保持不透明表面。原生连接画布的输入、分辨率协商与生命周期不因换肤改写。
- SwiftUI 渲染目录覆盖登录、桌面库/搜索空态和全部连接阶段，额外包含深色、长文本与启用/禁用按钮；离屏窗口固定为 inactive，减少动态效果的启停条件另做单测。系统设置切换、真实窗口键盘/连接及动效手感不能由静态图片代替，验收单独记录。

## 验证

Web 每个变更路由需覆盖 1280px 与 320px、浅色与深色、简体中文与英文，并完成键盘走查、水平溢出检查与真实状态渲染。表格属于显式横向滚动容器，页面根节点不得横向滚动；表格内标识完整保留，不在数据层截短。macOS 按上一节的原生窗口尺寸与当前支持语言验收，不套用浏览器视口或 DOM 断言。
