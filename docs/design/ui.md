# UI 设计语言

## 定位

管理控制台是管理员和专业用户长时间操作的工具，不是营销页面。信息要能快速扫描，但只显示当前任务所需的信息；状态、错误和下一步必须直接可操作。

视觉语言由本仓库拥有。首批语言为简体中文和英文，导航与按钮按更长的英文标签预留空间。浅色与深色从第一版同时支持，并跟随或覆盖系统外观。管理员、桌面用户和 AI 监督者共用组件，但界面密度按角色区分。

产品展示名统一为 `VC Workspace`。Web 标题、登录品牌、macOS 应用名、远程桌面窗口标题和用户文档不得继续显示旧展示名。`vc-vdi` PVE 标签、环境变量前缀、OIDC URL Scheme、Bundle ID、包名与既有来宾路径属于兼容性标识，不随展示名迁移。

官方标志为 `Agent Fabric`：中心工作空间连接三个不对称节点，分别承载集群资源、用户终端与 AI Agent 的关系。主标志与应用图标的唯一源文件位于 `assets/brand/`；Web Landing、登录页、控制台、favicon 与 macOS Bundle 必须从这些资产派生，不在各端重画近似版本。应用图标固定使用暖黑底与米白标志，在浅色和深色主题中均不着色、渐变或添加状态装饰。官方品牌标志只承担身份识别，不复用为功能按钮图标。

## 公共 Landing Page

根路径是给首次接触项目的自托管用户、基础设施团队和开源贡献者阅读的项目入口，属于一页读完并完成一次选择的 pitch surface；`/console` 才是操作应用。视觉语言仍由本仓库拥有，不另起一套营销主题。简体中文和英文同时交付，短导航与按钮按更长文案预留两倍伸缩空间；浅色和深色均为首发状态。

- 首屏只承载产品名、一句明确定位、一个主操作和一份能证明闭环的产品结构图。主操作进入 `/console`；GitHub 是同尺寸、弱填充的次操作。
- 定位必须点明 PVE、自托管工作空间、原生客户端和 MCP，不使用“下一代”“企业级”“无缝”等无法验证的形容词。
- 首屏之后只解释仓库中已经存在的四条能力边界：控制平面、原生客户端、镜像与 GPU、Agent 与 MCP；不为尚未形成闭环的功能创建占位页面。
- 公开仓库地址固定为 `https://github.com/Veritas-Calculus/vc-workspace`。仓库第一次 push 前不展示 Star、Release、版本号、许可证类型或可复制安装命令；这些信息只能由真实仓库状态生成。
- Landing 与控制台共享品牌、主题和语言控制。公开页语言当前保存在本地偏好中；在正式公开部署前再决定并实现可索引的语言路径与 `hreflang`，不能把当前客户端切换误报为 SEO 完成。
- 首屏只允许一个填充按钮；不使用持续动画、入场隐藏、背景光效或滚动劫持。交互只保留现有短时 hover/focus 反馈，并尊重 `prefers-reduced-motion`。
- 文本均来自统一消息目录。标题允许自然换行，不截断；导航允许换行或收起；架构标签与代码标识保持 LTR；根节点在 320–1280px 不得产生横向滚动。

## 视觉规则

- 基础色使用无彩中性色，主操作使用墨色反转，不引入无来源品牌色。
- 成功、警告、信息和错误只用于真实语义状态；同一状态在全产品使用同一 Token。
- 界面依靠层级、留白和 1px 分隔线组织，不使用投影。
- 圆角只有 `control`、`panel`、`pill` 三个命名用途；普通工作区面板保持克制。
- 标题使用短字号阶梯；表格、表单和导航优先保证扫描节奏。
- 动效只用于即时状态变化，并尊重 `prefers-reduced-motion`。

## 信息规则

- 不显示“OIDC 可用”“企业级”“已就绪”等无法触发动作、不能帮助判断的标签。
- 品牌、页面标题、说明句和主按钮不重复表达同一件事；登录页只保留品牌、凭证字段和登录动作。
- 登录页的品牌与表单属于同一个居中内容组，间距保持一个普通章节级空隙；语言和主题工具悬置在视口角落，不再用独立顶栏把品牌与登录动作拆到视口两端。
- macOS 主窗口使用无标题栏样式，保留系统红黄绿窗口控制，但不在窗口顶部重复显示产品名或分隔条；产品名只在登录内容区出现一次。
- macOS 普通用户登录后进入“桌面库”：顶部只保留页面名、搜索、刷新和退出，不向用户暴露“弱网”或协议调参。数据面始终使用自适应策略；特定带宽策略只能由管理策略或诊断工具注入。
- macOS 桌面库使用响应式卡片网格，卡片不随宽窗口无限拉伸。卡片只展示桌面名、运行状态、VMID、节点、CPU/内存和当前操作；名称与节点单行截断，通过系统帮助文本暴露完整值。搜索同时匹配名称、VMID、节点和状态，无桌面、搜索无结果、首次加载和加载失败必须是四个不同状态。
- 单页面产品不显示只有一个入口的导航；概览数字若已能从紧邻表格直接读出，则不重复展示。
- 不制造装饰性统计卡；概览只保留会影响调度或需要处理的资源信息。
- 空状态说明原因并提供唯一下一步；错误状态保留在页面中并允许重试。
- 列表默认截断长标识，完整值通过详情或复制动作获取。
- 管理端按真实工作流固定为“桌面 / 近期任务 / 基础设施 / 桌面镜像 / GPU 加速 / 访问控制 / 审计”七个一级工作区。普通用户只显示自己的“桌面”；其余工作区只对平台管理员显示。“访问控制”直接维护本地/OIDC 用户、AI Agent、Agent 凭证状态与两类桌面分配，不增加统计卡或装饰性概览。宽屏使用单一左侧导航，窄屏折叠为可横向滚动的顶部导航；不再叠加第二套页签。
- “桌面”只展示控制面明确标记为受管的实例，名称只用于展示和搜索，不能成为权限或能力判断依据。创建、启动和停止在当前工作区完成；异步结果统一进入“近期任务”。
- Web 桌面列表为每台受管桌面提供“在 VC Workspace 中打开”动作，使用兼容 URL `vc-vdi://connect?vmid=<正整数>` 唤起 macOS 客户端；Landing Page 不展示没有目标桌面的空泛“打开 App”。链接只携带 VMID，不携带控制面 Token、密码、Guest 地址或 RDP 描述符。客户端必须先从当前绑定的控制面重新读取登录用户可见桌面，匹配后才可启动或连接；未登录时保留一次待处理目标并在登录成功后继续，非法或不可见目标只显示错误，不产生桌面副作用。
- 原生打开动作不能伪造浏览器内的“已打开”成功状态，也不使用计时器猜测客户端是否安装。Web 提供明确的链接名称与系统原生行为；发布安装包和稳定下载地址形成闭环后再增加安装兜底。
- macOS 远程桌面画面必须处于 VC Workspace 自己的视图树和应用生命周期内，不得要求用户安装、启动或切换到另一个 RDP 应用。会话页使用整块黑色画布承载原生 `NSView`，固定工具栏只保留断开、桌面名、真实连接状态和全屏；连接中只显示一个居中的系统进度提示，断线后直接返回桌面列表并给出可操作错误。
- 全屏使用 macOS 原生窗口全屏，不另造沉浸模式；断开与窗口关闭都必须停止连接并回收会话。关闭主窗口不等同于退出应用：应用保留在 Dock，用户再次激活 Dock 图标时必须恢复同一个主窗口，并自动取消最小化或隐藏；只有显式退出才终止进程。远程画面跟随容器缩放，鼠标、键盘和剪贴板由同一个 AppKit responder chain 处理。
- 全屏按钮必须跟随窗口的真实全屏状态切换图标和可访问名称，无论通过按钮或 macOS 系统窗口控制进入全屏都一致。发布验收至少覆盖最小窗口、默认窗口、宽窗口、一次全屏往返，并在缩放后复测画面填充、鼠标命中和键盘焦点。
- “基础设施”集中展示 PVE 节点和存储；原始模板与普通 PVE VM 不混入最终用户的桌面列表。
- 用户、OIDC、会话策略和 AI 管理只有在对应 API 与可执行操作形成闭环后才加入导航，不使用空白页面预告路线图。
- 镜像列表只显示 OS、状态、模板 VMID、Agent 和编辑动作；ISO、软件源、CPU/内存/磁盘、固件/TPM 和 GPU 默认值放入编辑对话框，避免把低频配置铺满首屏。
- 镜像编辑对话框同时承担 Bootstrap：按“构建来源 / 硬件 / 可用性 / 构建模板”分组，Debian 展示软件与安全更新镜像源，Windows 展示驱动 ISO 和镜像名称；默认值可以指向 `10.31.0.2`，但环境参数不写死为唯一来源。
- “构建模板”是明确的提交动作，一次性密码和产品密钥必须和持久配置分区，并说明不会保存。构建开始后关闭编辑入口，在镜像页原位显示进度和最新脱敏日志；成功状态为“验证中”，不能直接变成“可用”。
- GPU 页面只显示档位、PVE 映射、可用性、状态与编辑动作，再单列 PVE 实际硬件。完整直通显示可分配设备数；mdev 显示指定类型的实时剩余实例数，不把两种口径混在一起。
- GPU 编辑对话框中的“创建 PVE 映射”默认收起；完整直通要求映射 ID 和一台当前可直通设备，mdev 只要求映射 ID 并自动收集支持该类型的节点。没有兼容设备时明确显示空状态且不能提交，不把宿主机准备步骤塞进对话框。
- 创建桌面只列出管理端已启用且构建状态为可用的镜像；选择 GPU 档位后，目标节点列表立即缩小到映射中实际可分配的节点。
- 审计工作区只显示时间、操作者、事件、目标和成功/失败结果；来源地址、客户端、原始事件类型及结构化详情按行展开。搜索和结果筛选由服务端执行，更早记录用游标加载；不复制任务统计，也不展示无操作价值的汇总卡。
- 溢出策略必须按内容类型声明：工作区导航窄屏横向滚动；数据表放在独立横向滚动容器；名称和任务详情在固定列中截断并用 `title` 暴露完整值；表单标签允许换行；页面根节点不得横向滚动。

## 刻意不做

- 不做渐变、玻璃、光晕和大面积阴影，它们会与高密度运维信息争夺注意力。
- 不使用大圆角卡片网格承载每个数字，它会把相关数据拆散成装饰模块。
- 不用徽章重复普通文案；徽章只表达状态或范围。
- 功能图标不用 Emoji 或临时手绘 SVG，统一使用 Lucide；官方品牌标志是身份资产，不受此规则约束。
- 不在页面上预告尚未实现或无法操作的功能。
- Landing 不做假指标、Star 计数、证言、Logo 墙、价格、FAQ、视频首屏、渐变光效或多段重复 CTA；它们都不能帮助首次访问者验证当前开源实现。
- MVP 不把 Universal Links 作为任意自托管部署的默认入口。它要求发布签名中的 Associated Domains 与站点上的双向关联文件，无法动态覆盖未知部署域名；项目拥有稳定 HTTPS 域名和签名发布链后，可把 Universal Link 作为 `vc-vdi://` 之上的可选可信跳转层。

## 验证

每个变更路由需覆盖 1280px 与 320px、浅色与深色、简体中文与英文，并完成键盘走查、水平溢出检查与真实状态渲染。表格属于显式横向滚动容器，页面根节点不得横向滚动；表格内标识完整保留，不在数据层截短。
